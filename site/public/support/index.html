Before reporting

Safe diagnostic checklist

  • Record the Ensync and operating-system version.
  • Record the provider CLI name and exact version.
  • Say whether the task used the local host or an SSH worker.
  • Include the exact error after removing secrets.
  • State whether a command, tool call, or file mutation began.
  • Do not include passwords, tokens, API keys, private keys, or subscription cookies.
  • Include only the minimum source context needed to reproduce the issue.
  • For a download issue, include the platform and release-manifest status shown on the site.
