How it works

Change the agent. Keep the work.

A coding task lives above any one provider. Ensync keeps its identity—project, transcript, feature memory, instructions, and verified Git state—together and hands it across the CLIs you already log into.

Safe handoff by default Fallback continues only before any mutation. Timeouts, malformed output, tool activity, or unknown work always stop for review.

  1. Connect your CLIs once

    Ensync discovers the signed-in official tools on your computer. Each vendor keeps its own account and subscription.

  2. Ask once

    Auto picks an eligible runner and runs in an isolated worktree branched from your clean checkout.

  3. It lands and delivers

    Compatible commits merge in order, push to origin, and report live status to Production—or just hold the exact commit.

Remote control

Run jobs from your phone.

The iOS and Android client—or the same app installed as a web PWA—signs into your self-hosted Ensync Sync service and controls a paired computer. Start, follow, stop, and steer Codex or Claude Code jobs while the Host keeps owning the run.

  • Claim a one-time pairing code from desktop Settings
  • List paired hosts and submit a job with a project path the Host re-verifies
  • Poll and decrypt progress events live, then stop or steer the turn
  • Everything is end-to-end encrypted (AES-256-GCM); Sync never sees plaintext
  • Installable from the phone home screen with no App Store required
  • Project discovery, attachments, approvals, background push, and OS keychain still planned
  • App Store and Play Store signing not yet published
