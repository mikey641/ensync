# Ensync logo exploration

The selected direction is **Continuity Loop**: two bounded provider sessions interlock around one shared task. The mark preserves the linked-loop shape already present in Ensync while tying it directly to provider-neutral continuity, safe handoff, durable conversation state, and protected project context.

## Deliverables

- `ensync-mark.svg` — responsive monochrome symbol using `currentColor`
- `ensync-logo.svg` — teal symbol with the lowercase Ensync wordmark
- `ensync-app-icon.svg` — flat charcoal/teal app-icon treatment
- matching `ensync-*.png` exports for review and handoff
- `concepts/` — six editable, feature-led SVG directions with PNG previews
- `showcase.html` — self-contained comparison and application board
- `ensync-mark-v2.svg` / `.png` — heavier monochrome-first Continuity Loop
- `ensync-logo-v2.svg` / `.png` — AI-style primary lockup with lowercase wordmark
- `ensync-app-icon-v2.svg` / `.png` — mint-on-charcoal application icon
- `ai-concepts/` and `showcase-ai.html` — alternate AI-emblem study and selected v2 presentation

## Brand tokens

- Charcoal: `#202123`
- Teal: `#19C69A`
- Mint on charcoal: `#7EE2BC`
- Paper: `#F7F7F3`

Keep clear space around the mark equal to roughly one capsule thickness. Use the monochrome mark below 24 px, avoid gradients and shadows, and do not redraw the two loops with different proportions. The wordmark uses Inter with system fallbacks; convert the text to outlines before sending artwork to a vendor that cannot guarantee the font.

Trademark clearance has not been performed. Complete a similarity search before adopting the mark publicly.
